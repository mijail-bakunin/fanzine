# La Guillotina

Frontend de una revista/fanzine digital construido con React y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Datos y API

Sin configuración adicional, la aplicación usa los datos provisionales locales de `src/data/mockEdition.js`.

Para conectar el backend, copiá `.env.example` como `.env.local` y configurá `VITE_API_BASE_URL`. El contrato de endpoints está documentado en `src/api/README.md`.

## Compilación

```bash
npm run build
```
